# Paper Artifacts

This folder stores reproducibility references for manuscript outputs.

- `expected_reference.json`: key numerical values used by `scripts/verify_outputs.py`.
- `checksums.txt`: SHA256 hashes for selected `results_v3` outputs from the run behind the reviewed version.
- `revision_r1/`: aggregated results of the revision. They contain no station identifiers.
- `dwd_open_demo/`: DWD audit tables for the revised configuration.

If you regenerate outputs on the licensed full dataset, recompute hashes before final release.
