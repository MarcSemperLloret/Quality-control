# Pressure-extreme influence diagnostics

`pressure_extreme_influence.csv` records the aggregate pressure-tail diagnostics used in the revised analysis. It contains no station identifiers or raw AVAMET observations.

The three rows describe the full 501-station pool, the 447 stations with less than 1% of records flagged, and an exploratory 446-station subset excluding the largest contributor to flagged high-tail values. Selection by flag rate uses the full archive; the exclusion is a post-hoc influence check. Neither subset is an independent release test or confirms whether removed raw extremes are true weather observations.

Events are counted in TEST (2025), using station-specific lower and upper 1% pressure-anomaly thresholds estimated in TRAIN (2023–2024). Rates equal `1 - flagged / events`. `n_stations` is the size of each group, not the number of stations contributing extreme events. `exploratory_subset` identifies the two post-hoc subsets.

Generation, from the repository root with the licensed-data network pool already prepared:

```bash
python scripts/28_pressure_extreme_trace.py WORK_DIR OUT_DIR
```

`WORK_DIR/pool/pool_coords.csv` and `WORK_DIR/pool/pool_all.parquet` are required. Raw AVAMET records require permission from the provider and are not redistributed. See [the workflow guide](../../docs/WORKFLOW.md) and the export script for the alignment, neighbour and quorum settings.

The first two rows agree with `pressure_extreme_retention.csv`; this export additionally supplies flagged counts and the influence subset. It adds audit outputs without changing scientific code or results. The CSV was generated by the exporter present in `ems-revision-r1.1`; it was committed afterwards and is not part of that immutable tag.

The SHA256 file is relative to the repository root:

```bash
sha256sum -c paper_artifacts/revision_r1/pressure_extreme_influence.sha256
```
